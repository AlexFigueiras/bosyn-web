Perguntas frequentes

O que todo escritório pergunta antes de assinar.

Meu cliente precisa instalar algum app?

Não. O portal do cliente funciona direto no navegador, com layout adaptado para celular.

Consigo trocar de plano depois?

Sim, o upgrade é feito direto no painel de assinatura. Se o trial vencer, você nunca perde acesso: cai automaticamente no plano Gratuito.

O que é a integração BOSYN?

É a ligação nativa com o Multiflow, o sistema de WhatsApp da BOSYN: cobrança de parcelas por etapa, lembretes e agendamento de reuniões automáticos, exclusivo do plano Estúdio.

Cada cliente vê os projetos de outros clientes do meu escritório?

Não. Cada cliente só acessa o próprio projeto — o isolamento é garantido em nível de banco de dados, não só na tela.
